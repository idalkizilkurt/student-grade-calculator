# 🎓 Student Grade Calculator

A simple Python application that calculates a student's weighted average and determines the letter grade.

## Features

- Enter student name
- Enter midterm and final grades
- Calculate weighted average
- Determine letter grade
- Modular structure using functions

## Project Structure

```
student_grade_calculator/
│
├── grade_utils.py
├── proje.py
├── README.md
├── requirements.txt
└── .gitignore
```

## Technologies

- Python 3

## How to Run

```bash
python proje.py
```
